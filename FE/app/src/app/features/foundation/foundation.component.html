Multi-Tenant Context

In this multi-tenant architecture, each physical mobile phone shop operates with segregated inventory, sales, and user accounts partitioned by shop_id.

Angular ApiRequestInterceptor attaches this header to all outgoing API calls.
Isolation Mechanism:
  • Single shared SQLite database file
  • Every business table indexed on (shop_id, ...)
  • Row-level tenant scoping enforced at service layer
  • Prepared statements guard against SQL injection

Frontend

Angular 14 + Bootstrap 5
  • Modular architecture (Core, Shared, Features)
  • Type-safe reusable ApiService + Interceptor
  • Bootstrap 5 & Bootstrap Icons styling
  • WCAG 2.2 AA compliant focus states & landmarks

Backend

Node.js + Express + TypeScript
  • Express REST API architecture
  • Zod request validation schema foundation
  • Centralized error handling & 404 middleware
  • Endpoints: /api/health & /api/version

Database

SQLite (better-sqlite3)
  • Foreign key constraints strictly enforced
  • WAL journaling for concurrent read/write stability
  • Safe parameterized queries & atomic transactions
  • Lightweight migration & seed runners
